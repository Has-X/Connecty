# Installer artwork

Light and dark backgrounds were generated with the built-in image generation
tool, then fitted to Inno Setup's 497:360 aspect ratio and optimized as PNGs.
They are installer-only assets; the running app does not load them.

Prompt: abstract Fluent 2 blue glass tunnel ribbons at the far right edge;
quiet pale-blue or charcoal-navy space across the left and centre for native
installer controls; no text, logo, symbols, arrows or UI mockup.
